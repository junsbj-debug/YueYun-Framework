# YueYun Framework

Open framework for household-centered long-term AI collaboration and digital continuity.

家庭本位长期AI协同与数字连续性开放框架

---

# 1. Core Positioning

YueYun Framework is an open engineering framework exploring household-centered long-term AI collaboration, distributed digital continuity, and civilization-scale resilience.

Its core mission is to ensure that humans remain the center of civilization in the AI era, while AI serves only as an acceleration tool for human digital civilization.
